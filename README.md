# 학교 분실물 관리 프로젝트

간단하게 파이썬으로 기본적인 틀만 만들어볼 예정
추후 자바 스프링부트로 변경할 예정
스프링부트에서는 db도 연결할 예정

## 기능
1. 분실물 추가
    딕셔러니 형태로 만들어서 나중에 JSON으로 주고 받는 것처럼 구현
    {id:{"이름":???, "장소":???, "상태":True/False}}
2. 분실물 검색
    전체 검색(스프링부트에서는 페이지네이션으로 만들예정)
    포함된 이름으로 검색
    장소로 검색
3. 찾으면 찾았다고 표시
    스프링부트에서는 찾은 시간으로 부터 특정 시간이 지나면 자동으로 삭제 되도록 구현
4. 찾아간 학생도 저장
